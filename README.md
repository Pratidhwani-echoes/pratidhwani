# Pratidhwani - an echo of abandoned missions
Pratidhwani is an interactive exhibit about eight spacecraft and programs that have contributed to our understanding of the Universe of which we are a part. This website is an attempt to preserve the memory of these missions.

It is aimed at teaching school-age space enthusiasts and curious minds of all ages about human ingenuity and innovation. Thus, a gamified approach involving the principle of "active learning" is emphasized by following up the reading with a quiz and questions to ponder. To ensure ease of use and accessibility, a dictionary API 
is utilised to provide definitions within the website itself, eliminating the need for users to navigate away from the exhibit.
